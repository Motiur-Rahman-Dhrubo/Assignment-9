# Discount PRO

### Welcome to Discount PRO !!!

##  Project name:

- Discount PRO

## Project Purpose:

- **Discount PRO** is a coupon collecting application designed to help users easily find and use discount coupons for popular e-commerce stores in Bangladesh. The app aggregates various vouchers and coupon codes, allowing users to save money while shopping online. Users can sign up or log in via email or Google account using Firebase Authentication. After logging in, users can browse available coupons, view details like discount amounts, expiry dates, and product categories, and copy coupon codes with a single click to apply them at checkout.

## key features of the project:

- 1 . User Authentication - Sign up and log in using email or Google account via Firebase Authentication.
- 2 . Coupon Aggregation - Collects and displays all available discount coupons from popular e-commerce stores in Bangladesh.
- 3 . Coupon Details - View detailed information about each coupon, including discount amounts, expiry dates, and applicable product categories.
- 4 . One-Click Copy - Easily copy coupon codes with a single click for fast and convenient application at checkout.
- 5 . User-Friendly Interface: - Clean, simple interface that allows users to browse and filter through various coupons.
- 6 . Mobile and Desktop Compatibility - Responsive design for a smooth experience on both desktop and mobile devices.
